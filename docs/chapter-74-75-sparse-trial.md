# Sparse Authoring Trial: Chapters 74-75

## Verdict

**Keep the sparse format. It measurably reduced author-written record bulk,
but net token or dollar savings are not established.** Independent source/cue
review remains necessary. This is not evidence that weaker creative agents are
equivalent or that these cues improve image generation or learner recall.

The same stronger author handled both chapters. Main independently reviewed the
real source and all materialized cues. A separate non-author AI reviewer checked
the new materialization core and concrete repair deltas. No human specialists or
paid external providers were used. The extra code-review lane and tool/test
development are setup costs, not free efficiency gains.

## What Was Actually Reduced

The author selected terms and native page/span IDs rather than retyping source
text, fonts, coordinates and printed-page metadata. Code copies that evidence.
An explicitly selected unchanged same-term reference inherits its actual cue and
scope. The author still supplies every new/modified/aliased semantic choice,
hold, scope and comparison; there is no automatic cue admission.

First validated drafts used 50 minimal unchanged-reuse rows and 135 full semantic
rows. Final drafts use 52 and 133. Many terms needed real creative or alias
judgment, so sparse reuse did not eliminate most semantic work in this cohort.

Combined author record bytes per term fell **36.3%**. Inventory bytes per term
fell about 57.4%; decision bytes per term fell about 15.0%. These are file-byte
measurements, not billed tokens or context-read totals. The new cohort has fewer
pages, different topics and fewer repeated keyword occurrences. Main tooling,
tests, review and integration are not included in these author-file figures.

Sparse inventory took about 5.1 elapsed minutes. First validated cue freezes were
about 5.7 and 9.0 minutes after the first observed phase-two timestamp, versus
14.2 and 22.1 minutes previously. The current cohort is less than half as many
terms. Neither raw completion time nor fewer agents proves causal or net savings.
Exact per-agent billing/quota weights are unavailable. Codex account usage was
consumed even though no Anthropic API calls occurred.

First counts were 60/24/46/1 and 21/10/22/1 for different bridges/variants/repeats/
holds. Main requested one bounded repair round per chapter: four and one changed
decision records. These were chiefly accounting/provenance corrections, not five
equally serious cue failures or an image-quality score.

- Neuropathies reused an existing standalone nerve bridge; no real visual variant.
- Magnesium and polyethylene glycol did not become fresh variants merely because
  old scope wording was clarified. Actual selected repeats were reselected.
- Strictures already had the narrowing-tube bridge under a different headword.
  Exact-term retrieval alone missed that semantic alias; the belt accessory did
  not establish a different encoded bridge.
- Hemodynamically stable changed the state of an existing blood/balance bridge;
  it is a variant, not a fresh association family.

Preparation repairs are not hidden: the inventory initially duplicated a whole
coordinated appearance clause instead of mapping its actual heads. Before cue
freezes, the author corrected two circular local self-references in 74 and one
reference/scope issue in 75. Initial saved files remain separately preserved.
No first-frozen hold was resolved. Ogilvie's syndrome and Sengstaken-Blakemore
tube remain held for weaknesses of their particular attempted assemblies, not
because all partial names or taught categories must identify complete terms.

Independent tool review caught nonpositive prior selection and a changed-copy
loophole, including its alternate retain-status bypass. Tests now reject these.
Compact source references preserve traceability without tracking full textbook
excerpts. Main added local-reference existence/selection/cycle checks from the
actual self-reference defect, correct native-highlight counting, and a main-only
hash-bound integration helper with preflight tests. A missing legacy scope can
be supplied in an explicit reviewed row without inventing a visual variant;
unchanged sparse inheritance still requires an existing nonblank scope.

Those implementation changes are trial setup/confounders, not a retrospectively
frozen end-to-end cost benchmark. The independent code lane reviewed the
materialization core and its named deltas; later integration/local-reference/
legacy-scope helpers were main-reviewed and regression-tested separately.

## Recommendation

Use the reusable tool and sparse contract for the next authorized batch. Keep
stronger cue judgment and independent materialized-output review. Do not add a
helper merely to dispatch scripts, or relabel metadata repairs as creative yield.
The remaining concrete weakness is bounded alias/head retrieval: same-term
lookup cannot recognize every synonymous bridge. Improve that only against
observed misses; do not replace it with another expensive whole-corpus census.

A later batch without initial tool setup can give a better effort comparison.
This trial supports less transcription and reusable integrity checks, not a
promise of a particular percentage reduction in account usage.
