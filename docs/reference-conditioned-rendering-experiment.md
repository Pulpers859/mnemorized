# Reference-Conditioned Full-Scene Trial

Date: 2026-10-17. Experimental visual-lab route; app defaults unchanged.

## Method

Continued the real eight-anchor introductory pericarditis Forge lesson. Source
retrieval, clinical gate, source/association review, bundle export and QA-pack
generation preceded the full render. Antigravity used only the supported native
chat/image lane, read the complete Constitution, and did not grade its output.

One native empty-room background became the reference for two successive complete
scene renders. The second used the empty background again, not the failed complete
image. Both accepted native ImagePaths conditioning. This is not alpha-cutout or
deterministic coordinate compositing. Native outputs are 1376x768 opaque RGB PNGs.

All eight teaching units remained in the lesson. After the first image failed,
Forge repaired the three implicated units. Subsequent concision restored exact
generated text from a format-failed Forge response as an explicitly unapproved
draft, followed by fresh real source/preflight gates and independent source review.
No medical or replacement scene prose was hand-authored. The original strict-parser
failure remained failed; no parser, source gate or pixel rubric was weakened.

## Independent Results

Both external AI auditors inspected native and normal-1024-wide pixels, the actual
eight-unit bundle and full supplied sources, without seeing the other's report.

## Effort And Failure Accounting

Three native image calls: one background and two complete scenes. The same packet
also contains **44 unique completed Anthropic responses**, 845118 input tokens
and 46507 output tokens, across its captured text/source/review/repair trials.
These counts exclude independent Codex reviewers, retrieval/embeddings, earlier
run roots and native image cost. No monetary estimate is available.

Repeated character-budget retries were inefficient. A candidate initially believed
shorter measured one word longer and was not rendered. The final prompt is shorter
by both actual measures: 256 words / 1626 characters versus 262 / 1670. Prior failed
trials remain failed. Request-layout tests prove serialization, not improved model
obedience. The critic also produced false-positive counts and field repair emitted
prose before JSON. These are unresolved first-pass reliability risks, not successes
hidden behind the final image.

## Judgment And Limits

Background reference conditioning is worth further controlled testing: this trial
preserved coherent architecture with substantially fewer native calls than the
earlier eleven-call coordinate-layering pilot. It does **not** establish superiority:
the lesson, associations, source corrections and effort differed between pilots.
No default renderer was changed on the basis of one adaptive topic.

The canonical 100 is not a claim of perfect self-decoding, learning retention or
current clinical guidance. Exact values, treatment names and some causal detail
still require narration. The risk scale is tilted without visible load weights;
movement direction is not conclusive in a still; anatomical pericardium is not
independently delineated. Both reports document these limits rather than inventing
unlisted score deductions or pretending every literal detail was followed.

The next reliability work should reduce format/repair waste and test a frozen
fresh-topic cohort, with first artifacts and failures retained. Another polished
recovery is not evidence that the default app can one-shot new topics.
